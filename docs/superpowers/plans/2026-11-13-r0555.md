**Goal:** close the deferred entries F1 to F4 and build the lightness items L1 to L7, L9 and L10 of the spec, each as a small
task with its tests first, so 0.55.5 writes, reads and logs less than 0.55.4 and loses nothing.

a batch; F4 is a check before the estimate that clears a batch whose every entry would drop out. The lightness items each
remove a write, a read, a process or a line where nothing needs it.

the test VM for root, loop-image, mergerfs and power-loss tests (`mkfs.f2fs`, `mkfs.ext4`, `mkfs.xfs`, `f2fs_io`).

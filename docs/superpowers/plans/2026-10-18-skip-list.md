# Per-job Skip List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let each job name a gitignore-style skip-list file in the rule TSV, and keep matching paths out of watches, copies and new versions.

**Architecture:** A `SkipList` object (compiled `pathspec.GitIgnoreSpec` plus a fingerprint) is threaded through every reader of the monitored tree: a `skip` predicate on `iter_tree_entries` prunes walks, and `watchFolder` filters events and watches. A per-job `JobStartup` object lets the backuper load the list once the job's filesystems are ready, compare its fingerprint with the one recorded in the manifest `meta` table, and only then decide between replaying pending transactions and a full comparison. Nothing that reads the vault applies the list.

**Tech Stack:** Python (single module `reverberator.py`), `pathspec` (new), sqlite manifest, `inotify_simple`, TSVZ, pytest via `uv run --extra test pytest`.

**Spec:** `docs/superpowers/specs/2026-10-18-skip-list-design.md`

## Global Constraints

- Dependency: add `"pathspec>=0.11"` to `[project].dependencies` in `pyproject.toml` (`GitIgnoreSpec` exists from 0.10; 0.11 is the last line supporting Python 3.7, so `requires-python = ">=3.7"` stays). Regenerate `uv.lock` with `uv lock`.
- Patterns match paths relative to the monitored folder; folders carry a trailing `/` (the `iter_tree_entries` convention). The monitored root is never skipped.
- The skip list is applied only where the monitored tree is read, never where the vault is read (`decrement_stepper`, `manifest.rebuild(version_path)` without `tree_path`, `read_vault_record`, `do_referenced_copy`, retention).
- A skip-list failure stops only its own job: it must never clear `GREEN_LIGHT`.
- The recorded fingerprint must only change in the same sqlite transaction that commits a version, or after a delta comparison that completed with no differences.
- Code style follows `reverberator.py`: tabs, existing naming mix, comment density, doctests on small pure helpers.
- Tests never read or write the repo's own `reverb_rule.tsv`.
- Runner: `uv run --extra test pytest` (full). Fast loop, unit tests plus the module's doctests (doctests carry no marker, so `-m unit` alone would drop them): `uv run --extra test pytest -m "not inotify and not process and not privileged"`. New test modules set `pytestmark`.
- Commit messages: one plain sentence in the repo's style (e.g. "Prune skipped paths from tree walks."), ending with the `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` trailer.
- Version becomes `0.37` (`__version__` and `pyproject.toml`).

## Review Focus

- Rule files whose header cells carry trailing spaces (the repo's own `reverb_rule.tsv` has `Only Sync Attributes (permissions) `) or CRLF line endings must still be recognised and upgraded, keeping their line endings. Test: Task 2, `test_parse_rules_upgrades_old_header_in_place`.
- Skip lists saved with CRLF line endings or a UTF-8 BOM must behave exactly like LF files. Test: Task 1, `test_load_reads_crlf_and_bom_like_lf`.
- A skip list that is not UTF-8 text, or is a folder, is unreadable: the job refuses, no thread dies with a traceback. Tests: Task 1, `test_load_refuses_unreadable_lists`; Task 7, `test_load_binary_list_fails`.
- A pattern that matches everything (`*`) never skips the root; the job still commits a (near) empty version. Tests: Task 1, `test_root_is_never_skipped`; Task 3, `test_skip_everything_still_commits_v0`.
- Names beginning with `#` or `!`, or containing spaces, are literal names unless the pattern escapes them (`\#draft`), and a `#...` line is a comment. Test: Task 1, `test_names_starting_with_hash_or_bang`.

**Files:**

**Interfaces:**
- Produces:
  - `class SkipList` with
    - `__init__(self, monitor_path:str, lines=(), source:str = '')` — compiles `pathspec.GitIgnoreSpec.from_lines(lines)`; raises `ValueError` (pathspec's `GitIgnorePatternError`) on a bad pattern.
    - `SkipList.load(monitor_path:str, path:str) -> SkipList` (classmethod) — reads with `encoding='utf-8-sig'` and universal newlines, `source=path`; lets `OSError` and `ValueError` (incl. `UnicodeDecodeError`) propagate.
    - attributes `monitor_path`, `source`, `patterns` (list of the pattern lines that compile to a non-null pattern, i.e. `include is not None`, in order), `fingerprint` (`''` when `patterns` is empty, else `xxhash.xxh64('\n'.join(patterns)).hexdigest()`), `location_dependent` (bool).
    - `__bool__` — `bool(self.patterns)`.
    - `skips(self, rel:str) -> bool` — `False` for `''`/`'/'` or when there are no patterns, else `spec.match_file(rel)`. Callers guarantee rel's parent folder is not skipped (walks prune, and events only arrive from watched folders), so this checks the entry alone.
    - `skips_path(self, path:str, is_dir:bool) -> bool` — `skips()` on the path made relative to `monitor_path` (`/` appended for folders); `False` for the root and for paths outside it.
    - `folder_rel(self, folder_path:str) -> str` — `''` for the root, else the root-relative path with a trailing `/`.
  - `skip_list_change(recorded, current:str, explicit_none:bool) -> str` returning `'unchanged'`, `'changed'` or `'refuse'`.

	sl = rv.SkipList(str(tmp_path), ['build/', '*.log', '!keep.log', '/top', '# comment', ''])

		sl = rv.SkipList(str(tmp_path), lines)
		assert not sl and sl.fingerprint == '' and not sl.skips('a')

	b = rv.SkipList(str(tmp_path), ['# header', '*.tmp', '', 'cache/'])
	assert a.fingerprint == b.fingerprint != ''
	assert a.fingerprint != rv.SkipList(str(tmp_path), ['cache/', '*.tmp']).fingerprint
	assert a.fingerprint == rv.SkipList('/elsewhere', ['*.tmp', 'cache/']).fingerprint

	for pattern in ['*.tmp', 'node_modules/', '**/cache/', '!keep.tmp', 'build']:
		assert not rv.SkipList(str(tmp_path), [pattern]).location_dependent, pattern
	for pattern in ['/scratch/', 'projects/*/build/', 'a/b', '!/top', '**/x/y', 'a/**']:
		assert rv.SkipList(str(tmp_path), [pattern]).location_dependent, pattern


def test_load_reads_crlf_and_bom_like_lf(tmp_path):
	lf = tmp_path / 'lf'
	lf.write_bytes(b'*.tmp\ncache/\n')
	crlf = tmp_path / 'crlf'
	crlf.write_bytes(b'\xef\xbb\xbf*.tmp\r\ncache/\r\n')
	a = rv.SkipList.load(str(tmp_path), str(lf))
	b = rv.SkipList.load(str(tmp_path), str(crlf))
	assert a.fingerprint == b.fingerprint
	assert b.skips('x.tmp') and b.skips('cache/') and b.source == str(crlf)


def test_load_refuses_unreadable_lists(tmp_path):
	with pytest.raises(OSError):
		rv.SkipList.load(str(tmp_path), str(tmp_path / 'missing'))
	with pytest.raises(OSError):

  - `JobStartup.load(self, recorded_fingerprint) -> bool` — builds `SkipList(monitor_path)` when `skip_list_path is None`, else `SkipList.load(monitor_path, skip_list_path)`; on `OSError`/`ValueError` logs an error naming the job and the file and fails; otherwise sets `change = skip_list_change(recorded_fingerprint, skip_list.fingerprint, explicit_none)` and fails on `'refuse'` with an error telling the user to set the job's Skip List File to `none` to back up everything. Logs the pattern count and source once on success. Always sets `loaded`; sets `failed` on failure; returns success.
  - `watcher(..., max_shapshot_delay_seconds=..., startup=None)` — when `startup` is given, after the monitor fs wait: wait (`GREEN_LIGHT` loop) for `startup.loaded`; if `startup.failed`, log and `return False` without touching `GREEN_LIGHT`; call `watchFolder(..., skip_list=startup.skip_list, watching=startup.watching)`.
  - `backuper(..., log_journal=False, startup=None)` — when `startup` is given, after the vault and monitor fs waits and before the first `to_process.take()`:
    1. open `manifest = VaultManifest(job_vault)` if `job_vault` is a folder, into the backuper's existing `manifest` variable (so `do_backup` reuses it and the `finally` closes it); `recorded = manifest.skip_fingerprint` (else `None`);
    2. `if not startup.load(recorded): return` (the `finally` still runs; `GREEN_LIGHT` untouched);
    3. wait (`GREEN_LIGHT` loop) for `startup.watching`;
    4. if `startup.change == 'unchanged'`: `restored = ChangeEventQueue(monitor_path)`, `resumed = load_pending_transactions_for_resume(job_name, monitor_path, vault_path, restored, startup.skip_list)`; else remove the pending transactions file if present (log that the skip list changed) and `resumed = False`;
    5. under `to_process_lock`: `to_process.prepend(list(restored))` when resumed, else `to_process.append(ChangeEvent(time.monotonic(), False, 'full_scan', monitor_path, None))` (a full scan absorbs whatever the watcher queued meanwhile);
    6. pass `skip_list=startup.skip_list` to every `do_backup` call.
    Without `startup`, behaviour is unchanged (existing tests call it that way).
  - `main`: per rule, `startup = JobStartup(job_name, monitor_path, resolve_skip_list_path(reverb_rule.skip_list_file, args.rule_path), reverb_rule.skip_list_file.strip().lower() == 'none')`; pass it to `watcher` and `backuper`; remove the `load_pending_transactions_for_resume` call at `:566` (the backuper now makes that decision).

def _run_backuper(job, startup, monitor_fs_flag=None):
	if monitor_fs_flag is None:
		monitor_fs_flag = threading.Event()
		monitor_fs_flag.set()
	thread = threading.Thread(target=rv.backuper, args=(job.job_name, rv.ChangeEventQueue(job.monitor), threading.Lock(),
		job.monitor, job.vault, 'N/A', threading.Event(), monitor_fs_flag), kwargs=dict(startup=startup), daemon=True)

	rv.GREEN_LIGHT.clear()
	thread.join(timeout=5)
	rv.GREEN_LIGHT.set()

	for dirpath, dirnames, filenames in os.walk(job.monitor):

	return pending

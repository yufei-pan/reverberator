**Interfaces:**
- Produces: `FSTAB_PATH = '/etc/fstab'`, a module constant that tests patch, like `MOUNTINFO_PATH`.
- Produces: `parse_fstab(content:bytes) -> list`. It returns the mount points, field 2 of each line, in file order. It skips blank lines, lines whose first non-blank character is `#`, and lines with fewer than 2 fields. Fields are split on whitespace. It decodes `\040` `\011` `\012` `\134` (on bytes, then `os.fsdecode`) and drops any field that is not absolute (`none`, swap). The rest go through `os.path.normpath`, so a trailing `/` goes. Give it a doctest.
- Produces: `fstab_mount_points() -> list`, which is `parse_fstab()` of `FSTAB_PATH` read as bytes. It is `[]` on any `OSError` (missing, unreadable, a folder). It is read at each call.
- Produces: `vault_disk_problem(path:str) -> 'str | None'`. It is None when the vault path's disk is there, else why not. It works on a path that does not exist. Exact texts:
  - `f'{mount_point} is not mounted ({FSTAB_PATH} names it)'`
  - `f'the mount table cannot be read: {e.strerror or e}'`, as `pool_state()` words it
  - otherwise `pool_problem()`'s text.

  Order, which the tests do not pin:

  ```python
  real = os.path.realpath(path)           # non-strict: a dead mount on the way is no error
  above = [mp for mp in fstab_mount_points() if mp == '/' or real == mp or real.startswith(mp + '/')]
  try:
  	mount_table = read_mount_table()
  except OSError as e:
  	return f'the mount table cannot be read: {e.strerror or e}'
  if above:
  	longest = max(above, key=len)
  	if not any(point == longest for point, _ in mount_table):
  		return f'{longest} is not mounted ({FSTAB_PATH} names it)'
  return pool_problem(path, mount_table=mount_table)
  ```

  An fstab mount point with a symlink in it never equals a realpath, so it never matches (fails open, as the spec says). The docstring says so.
- Produces (tests): `write_fstab(*mount_points:str) -> str` in `tests/harness.py`. It writes `rv.FSTAB_PATH` with one line `/dev/fake{i} <mount point escaped as fstab writes it> xfs defaults 0 0` per mount point, and returns the path.
- Produces (tests): `FakePool.add_mount(mount_point:str, fstype:str = 'xfs') -> str`. It makes the folder when missing, appends a plain mount line for its realpath (source `/dev/fake`), writes, and returns the realpath. `drop()` and `mount()` take it as they take a branch.
- Produces (tests): `FakePool.line()` writes the mount point octal-escaped as the kernel does (`\` → `\134`, space → `\040`, tab → `\011`, newline → `\012`). Existing paths have none of these, so nothing else changes.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A file or folder made or saved in a batch, then moved through folder moves and moved again, is copied once to where the batch leaves it, with no rename and no traceback. A rename that finds nothing in the version logs one warning instead of a traceback, then copies. Each start logs one warning per job name that is on more than one line of the rule file, and the file keeps those lines. Version 0.49.

**Architecture:**
- Goal 1 changes only the escalation in `change_events_to_backup_entries()`. The copy follows the entry's own later moves, which are dropped, and lands where the entry ends. A delete stays at the first destination, and is dropped again if an earlier move takes what the version holds there (Task 1).
- Goal 2 changes only the replay's move step `except` block. A `FileNotFoundError` from `os.rename` gets one warning, then delete and copy. When the live entry is gone too, it gets only the delete, plus dropping the rows the move put at the target (Task 2).
- Goal 3 adds `repeated_job_names()`, a pure function over the rule file's bytes that keys lines as TSVZ does. `parse_rules()` warns from it at the daemon's start. `rewrite_rule_rows()` keeps the earlier lines (Task 3).
- Task 4 is the version, the README, and docs/limitations.md.

```python
# state, beside moveSourceToDestDict: the first destinations whose escalation left a delete
escalation_deletes = set()

# in the move pre-handling, right after pendingMoveSourceParents.add(abs_moved_from): an earlier move takes what the
# version holds there away, so the escalation's delete there would remove what that move still needs
for gone in [p for p in escalation_deletes if p == abs_moved_from or (abs_moved_from.endswith('/') and p.startswith(abs_moved_from))]:
	escalation_deletes.discard(gone)
	if gone in backup_entries and backup_entries[gone].event == 'delete':
		del backup_entries[gone]

# in the escalation, after now_at, escalated_bound = carried(moveDest, ...) and before `if now_at is None:`
dropped_own = False
while own and now_at is not None and now_at != moveDest:
	stops = later.get(now_at) or []
	i = len(stops) if escalated_bound is None else bisect.bisect_left(stops, (escalated_bound,))
	if not i or stops[i - 1][1] is None:
		break                                   # something ended the path there: the copy lands as today
	dest = stops[i - 1][1]                      # the move carried() stopped at, by time
	if not (dest in backup_entries and backup_entries[dest].event == 'move' and backup_entries[dest].source_path == now_at):
		# chain merged on to its end: the dict's, only when nothing came to the path between them
		if i != len(stops) or now_at not in moveSourceToDestDict:
			break
		dest = moveSourceToDestDict[now_at]
		if dest not in backup_entries or backup_entries[dest].event != 'move' or backup_entries[dest].source_path != now_at:
			break
	del backup_entries[dest]
	if moveSourceToDestDict.get(now_at) == dest:
		del moveSourceToDestDict[now_at]
	dropped_own = True
	now_at, escalated_bound = carried(dest, entry_when.get(dest), True)
if now_at is not None and dropped_own:
	# the copy lands where the entry ends; what the version held at the first destination goes
	escalated = backup_entries.pop(moveDest)
	backup_entries[moveDest] = BackupEntryValues(escalated.iso_time,'delete',None)
	escalation_deletes.add(moveDest)
	if now_at not in backup_entries or backup_entries[now_at].event == 'attrib' or not stands(now_at, escalated_bound):
		backup_entries[now_at] = escalated
		entry_when[now_at] = escalated_bound
		backup_entries.move_to_end(now_at)
	moveSourceToDestDict[source_key] = now_at
elif now_at is None:
	...                                         # today's branch, unchanged
elif now_at != moveDest:
	...                                         # today's branch, unchanged
```

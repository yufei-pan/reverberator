**Goal:** An attribute-only change whose mtime moved is copied. A job can schedule full comparisons. A vault disk's failed sync keeps its copies unchecked until a reboot. Each job has a chain length. A batch of deletes the vault does not track makes no version. Version 0.47.

**Architecture:**
- Two optional rule-file columns (13 `Full Comparison Interval`, 14 `Chain Length`) are read from a 12-to-14-column file as it is. Their values reach the backuper as keywords through `job_attempt_starter()` (Task 1).
- Goal 1a is one rule in `record_vouches()` (Task 2). Goal 1b is a timer in the backuper's idle wait that appends a `full_scan` (Task 3).
- Goal 2: `sync_vault_filesystems()` returns a result per disk. A failed disk gets a marker carrying the boot id under the state folder, and `compare_scopes()` keeps its records unchecked while a marker of this boot stands for a disk holding the job vault (Task 4).
- Goal 3: the chain length sets the re-copy range. reverberator's own followers lose their 40-link cap, and the two steps that follow vault links through the kernel walk the chain hop by hop instead (Task 5).
- Goal 5 drops a batch's deletes of untracked paths before do_backup decides it has work (Task 6).

**Tech Stack:** Python ≥ 3.8, the single module `reverberator.py` (tab-indented), pytest, TSVZ.

- Produces: `parse_duration(text:str) -> float`, in seconds; raises `ValueError`. Lower-case the text and remove all whitespace. Either of those two logs one line `f'Error: Rule {job_name} has invalid Chain Length value: {cell}; use a whole number of links, {MIN_CHAIN_LENGTH} or more, or 0 for no limit. Using {value}'`.
- Produces: `job_attempt_starter(job_name, startup_args, watcher_args, backuper_args, monitor_gate=None, monitor_signature=None, backuper_kwargs:dict = None)`. def recorded_backups(monkeypatch):
	'''(kind, start, end) of each do_backup() call, kind 'whole' or 'batch', times monotonic.'''
	calls = []
	real = rv.do_backup
	def recording(entries, *args, **kwargs):
		start = time.monotonic()
		try:
			return real(entries, *args, **kwargs)
		finally:
			calls.append(('batch' if entries or kwargs.get('touched') is not None else 'whole', start, time.monotonic()))
	monkeypatch.setattr(rv, 'do_backup', recording)

## 2026-10-27 reverberator: an attribute-only change whose mtime moved is copied
- Changed: under Only Sync Attributes, an attrib whose live mtime differs from the recorded one now copies the file.
